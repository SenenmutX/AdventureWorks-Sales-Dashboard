# Sales & Revenue Performance Dashboard

## Overview
An end-to-end Business Intelligence project built with Power BI,
analyzing sales performance using the AdventureWorks2019 database.

## Tools Used
- SQL Server (AdventureWorks2019)
- Power BI Desktop
- DAX
- Power Query

## Data Source
This project uses the AdventureWorks2019 sample database by Microsoft.
Download it from:
https://github.com/Microsoft/sql-server-samples/releases/tag/adventureworks

After downloading, restore it on SQL Server and connect Power BI to it.
